Menu Options — English

  • Add Item: Adds a blank row. Enter the category, product name, brand, size/details, quantity, and price in CAD.
  • Language: Switches button labels, grocery category names, and this help guide between English and French, including the mobile menu, sorting, pagination, and dialog actions. The button shows the current language.
  • Summary Report: Opens saved shopping summaries and lets you add a report with the shopping date, store, actual cost, and optional reason. Estimated cost is calculated from picked-up items.
  • Statistics: Displays a chart comparing estimated and actual costs from saved summaries.
  • Help: Opens this guide.
  • About Solution: Displays information about Grocery Manager.
  • Save: Saves the current grocery list in this browser on this device. Summary reports are saved when you add them.
  • Download Data: Downloads the grocery list as a JSON backup file.
  • Download Summaries: Downloads saved shopping summaries as a JSON backup file.
  • Upload Data: Imports a grocery-list JSON file into the app.
  • Upload Summaries: Imports a summaries JSON file into the app.
  • Logout: Signs you out and returns to the login screen. On mobile, open the menu with the ☰ button; it contains the same actions except Logout is shown at the top.

Shopping List Controls — English

  • Edit category, product name, brand, size/details, quantity, and price directly in the table.
  • Check Picked Up for items you have bought. Picked-up items are used to calculate the estimated cost for a summary.
  • Use the trash button in the Actions column to delete an item.
  • Search filters the grocery list. Select Show only unpicked items to focus on items still needed.
  • Sort by Category and Sort by Product Name sort the list; click again to reverse the order.
  • Use Previous and Next to move between pages. The page summary shows how many items are displayed.
  • The totals show the number of matching items, the estimated cost for displayed items, and the sum of the Price column across all items, regardless of pickup status.

Backups and Transfers — English

Use Save to keep the list in the browser on the same device. Browser storage is device-specific and can be cleared, so download JSON backups regularly.

  1. Download Data and/or Download Summaries on the first device.
  2. Move the files to the other device (for example, using Google Drive).
  3. Use Upload Data and/or Upload Summaries in Grocery Manager on the other device.

If an upload fails, confirm that the file is a valid JSON backup from this app. Downloaded files are usually in your browser’s Downloads folder.

Options du menu — Français

  • Ajouter un article : Ajoute une ligne vide. Saisissez la catégorie, le nom du produit, la marque, le format ou les détails, la quantité et le prix en dollars canadiens.
  • Langue : Change les libellés des boutons, les noms des catégories et ce guide d’aide entre l’anglais et le français, y compris le menu mobile, le tri, la pagination et les actions des fenêtres. Le bouton indique la langue actuellement sélectionnée.
  • Rapport sommaire : Affiche les rapports d’épicerie enregistrés et permet d’en ajouter un avec la date, le magasin, le coût réel et une raison facultative. Le coût estimé est calculé à partir des articles ramassés.
  • Statistiques : Affiche un graphique comparant les coûts estimés et réels des rapports enregistrés.
  • Aide : Ouvre ce guide.
  • À propos : Affiche des renseignements sur Grocery Manager.
  • Enregistrer : Enregistre la liste d’épicerie actuelle dans le navigateur de cet appareil. Les rapports sont enregistrés lorsque vous les ajoutez.
  • Télécharger les données : Télécharge la liste d’épicerie dans un fichier de sauvegarde JSON.
  • Télécharger les rapports : Télécharge les rapports d’épicerie enregistrés dans un fichier de sauvegarde JSON.
  • Importer les données : Importe un fichier JSON de liste d’épicerie dans l’application.
  • Importer les rapports : Importe un fichier JSON de rapports dans l’application.
  • Déconnexion : Ferme votre session et retourne à l’écran de connexion. Sur mobile, ouvrez le menu avec le bouton ☰; il contient les mêmes actions, sauf que Déconnexion apparaît en haut.

Commandes de la liste d’épicerie — Français

  • Modifiez directement dans le tableau la catégorie, le nom du produit, la marque, le format ou les détails, la quantité et le prix.
  • Cochez Picked Up (Ramassé) pour les articles achetés. Les articles cochés servent au calcul du coût estimé d’un rapport.
  • Utilisez le bouton de corbeille dans la colonne Actions pour supprimer un article.
  • La recherche filtre la liste. Cochez Show only unpicked items (Afficher uniquement les articles non ramassés) pour voir ce qu’il reste à acheter.
  • Trier par catégorie et Trier par nom de produit trient la liste; cliquez de nouveau pour inverser l’ordre.
  • Utilisez Précédent et Suivant pour changer de page. Le résumé de page indique le nombre d’articles affichés.
  • Dans le rapport sommaire, utilisez Ajouter un rapport pour enregistrer un rapport. Utilisez Fermer pour quitter une fenêtre et Envoyer le courriel dans le formulaire de soutien.
  • Les totaux indiquent le nombre d’articles correspondants, le coût estimé des articles affichés et la somme de la colonne Prix pour tous les articles, qu’ils soient ramassés ou non.

Sauvegardes et transfert — Français

Utilisez Enregistrer pour conserver la liste dans le navigateur sur le même appareil. Les données du navigateur sont propres à l’appareil et peuvent être effacées; téléchargez donc régulièrement des sauvegardes JSON.

  1. Téléchargez les données et/ou les rapports sur le premier appareil.
  2. Transférez les fichiers vers l’autre appareil (par exemple avec Google Drive).
  3. Dans Grocery Manager sur l’autre appareil, utilisez Importer les données et/ou Importer les rapports.

Si l’importation échoue, vérifiez que le fichier est une sauvegarde JSON valide créée par cette application. Les fichiers téléchargés se trouvent généralement dans le dossier Téléchargements du navigateur.
